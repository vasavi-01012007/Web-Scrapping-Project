
# Flipkart Washing Machine Web Scraping & EDA

## 📌 Project Overview

This project focuses on collecting and analyzing washing machine product data from Flipkart using web scraping and Python.

The collected data is cleaned, analyzed, and visualized to understand product pricing, discounts, ratings, capacity, speed, and other important features.

## 🎯 Objectives

- Collect washing machine product data from Flipkart
- Clean and preprocess the collected data
- Perform Exploratory Data Analysis (EDA)
- Analyze pricing and product trends
- Create visualizations to understand the data
- Identify factors related to washing machine prices

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- BeautifulSoup
- Web Scraping
- Jupyter Notebook

## 📊 Dataset Features

The dataset contains information such as:

- Brand
- Capacity
- Machine Type
- Load Type
- Rating
- Reviews Count
- Offer
- Price
- Speed

## 🔍 Project Workflow

1. Data Collection using Web Scraping
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. Business Insights
7. Conclusion

## 📈 Analysis Performed

- Univariate Analysis
- Bivariate Analysis
- Price analysis
- Brand analysis
- Capacity and price analysis
- Rating and price analysis
- Discount and price analysis
- Reviews and price analysis

## 💡 Key Outcome

The analysis helps understand pricing patterns and product trends among washing machines listed on Flipkart.
